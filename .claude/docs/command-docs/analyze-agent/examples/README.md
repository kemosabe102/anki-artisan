# Analyze Agent Examples

Usage examples for the `/analyze-agent` slash command.

## Files

| File | Purpose |
|------|---------|
| `usage-examples.md` | Complete usage scenarios with expected outputs |

## Quick Reference

- **Single agent by name**: `/analyze-agent researcher-external`
- **Single agent by path**: `/analyze-agent .claude/agents/dev-tools/debugger.md`
- **Orchestrator analysis**: `/analyze-agent CLAUDE.md`
- **Ecosystem audit**: `/analyze-agent --all`

## When to Use Examples

- Learning the command for the first time
- Understanding expected output format
- Troubleshooting unexpected results
- Training new team members
