# Code Review Command Examples

Usage examples and complete workflow scenarios for the `/code-review` command.

## Files

| File | Purpose |

## Example Categories

1. **Basic Review** - Review uncommitted changes with default settings
2. **Security Focus** - Priority routing to sast-scanner agent
3. **Branch Comparison** - Multi-file batching across feature branches
4. **Resume from Checkpoint** - Recovery after Phase 4 failure
5. **Severity Conflict Resolution** - Agent disagreement handling
