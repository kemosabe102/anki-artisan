# Spec Command Examples

Example usage scenarios for the `/spec` slash command.

## Files

| File | Purpose | When to Read |
|------|---------|--------------|
| `usage-examples.md` | Complete workflow examples with expected output | Learning the command, debugging issues |

## Quick Navigation

- **Want to see full workflows?** → `usage-examples.md`
- **Need specific input formats?** → Check modes in main `spec.md`
- **Debugging output issues?** → Compare against examples

## Example Types

1. **Discovery Mode** (`/spec next`) - Finding candidates
2. **Roadmap Mode** (`/spec roadmap:ID`) - From roadmap item
3. **Guide Mode** (`/spec file:path`) - From guide file
4. **Free-form Mode** (`/spec "description"`) - From description
