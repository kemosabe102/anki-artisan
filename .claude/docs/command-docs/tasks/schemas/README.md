# Schemas

JSON schemas for the `/tasks` command output.

## Contents

| File | Description |
|------|-------------|
| `tasks.schema.json` | Schema for TASKS.json output file |

## TASKS.json Overview

The generated TASKS.json contains:
- Task definitions with IDs, descriptions, effort estimates
- Dependencies between tasks
- Agent assignments
- Review group markers
- Parallel execution flags
