## Quick Examples

### Single Plan Feature
```bash
/tasks docs/01-planning/features/simple-auth/
```

### Multi-Plan Feature  
```bash
/tasks docs/01-planning/features/005-regenerative-orchestration-system/
```

### Skip Validation (Fast Mode)
```bash
/tasks docs/01-planning/features/hotfix-feature/ --skip-validation
```
