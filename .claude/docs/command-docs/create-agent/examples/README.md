# Create Agent Command Examples

Usage examples and complete workflow scenarios for the `/create-agent` command.

## Files

| File | Purpose |
|------|---------|
| `usage-examples.md` | Complete workflow examples with expected output |

## Example Categories

1. **Basic Usage** - Standard template-based workflow
2. **Interactive Mode** - Using `--create-definition` for guided creation
3. **With Context** - Providing additional context via `--context-dir`
4. **Dry Run** - Preview mode without file creation
5. **Skip Validation** - Fast prototyping (high risk)
6. **Template Variants** - Using `--template=minimal|standard|comprehensive`
7. **Error Recovery** - Recovering from various failure scenarios
