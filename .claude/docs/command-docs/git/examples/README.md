# Git Command Examples

Usage examples and complete workflow scenarios for the `/git` command.

## Files

| File | Purpose |
|------|---------|
| `usage-examples.md` | Complete workflow examples with expected output |

## Example Categories

1. **Basic Usage** - Simple prepare/commit workflows
2. **Selective Commits** - Using `--groups` flag
3. **Skip Modes** - Using `--skip-validation` and `--skip-quality`
4. **Multi-Developer** - Handling remote sync and conflicts
5. **Error Recovery** - Recovering from various failure scenarios
