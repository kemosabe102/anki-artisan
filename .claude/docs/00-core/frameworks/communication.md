# Communication Frameworks

Frameworks for writing, presenting, and persuading.

## Pyramid Principle (SCQA)

| Aspect | Description |
|--------|-------------|
| **Full Name** | Situation, Complication, Question, Answer |
| **Core Elements** | Lead with the answer (BLUF), follow with supporting arguments grouped logically |
| **When to Use** | For written communication, executive summaries, and strategy documents |
| **Best For** | Structuring emails, memos, and proposals for busy executives |
| **Reference** | https://www.barbaraminto.com/ |

---

## AIDA

| Aspect | Description |
|--------|-------------|
| **Full Name** | Attention, Interest, Desire, Action |
| **Core Elements** | 4-stage persuasive flow to move an audience to action |
| **When to Use** | For persuasive writing, marketing copy, or high-impact cover letters |
| **Best For** | Marketing, professional summaries, persuasive pitches |
| **Reference** | https://www.copyblogger.com/aida-formula/ |

---

## Speak Memorably

| Aspect | Description |
|--------|-------------|
| **Full Name** | McGowan's Speak Memorably System |
| **Core Elements** | Headlines first, 'Scorsese' openings (action), Pasta & Broccoli (story+data), The Big Goodbye |
| **When to Use** | For scripting speeches, presentations, or important oral communications |
| **Best For** | Keynote speeches, all-hands presentations, avoiding 'death by PowerPoint' |
| **Reference** | https://www.harpercollins.com/products/speak-memorably-bill-mcgowanjuliana-silva |
