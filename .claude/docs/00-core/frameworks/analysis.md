# Analysis Frameworks

Frameworks for debugging, root cause analysis, and systematic problem decomposition.

## ReACT

| Aspect | Description |
|--------|-------------|
| **Full Name** | Reasoning and Acting |
| **Core Elements** | Reason → Act → Observe → Reason (iterative cycle) |
| **When to Use** | For complex technical problems, debugging, or tasks requiring sequential reasoning and tool use |
| **Best For** | Technical debugging, agent development, multi-step problem solving |
| **Reference** | https://arxiv.org/abs/2210.03629 |

---

## 5 Whys + Systems Thinking

| Aspect | Description |
|--------|-------------|
| **Full Name** | Iterative Why Questioning with Systems Perspective |
| **Core Elements** | Ask 'why' 5 times to find root cause; map feedback loops and interconnections |
| **When to Use** | When debugging recurring issues or understanding complex system failures |
| **Best For** | Root cause analysis, debugging distributed systems, post-mortems |
| **Reference** | https://www.mindtools.com/a3mi00v/5-whys |
