# Structured Execution Frameworks

Frameworks for large projects and process optimization.

## CAGEERF

| Aspect | Description |
|--------|-------------|
| **Full Name** | Context, Analysis, Goals, Execution, Evaluation, Refinement, Framework |
| **Core Elements** | 7-stage end-to-end problem solving lifecycle |
| **When to Use** | For major initiatives requiring a complete, disciplined lifecycle from start to finish |
| **Best For** | Large projects, complex initiatives, creating reusable organizational templates |
| **Reference** | https://github.com/minipuft/claude-prompts-mcp |

## DMAIC

| Aspect | Description |
|--------|-------------|
| **Full Name** | Define, Measure, Analyze, Improve, Control |
| **Core Elements** | Data-driven 5-phase improvement cycle (Six Sigma) |
| **When to Use** | For optimizing existing processes with clear performance metrics |
| **Best For** | Data pipeline optimization, SRE reliability projects, reducing defects |
| **Reference** | https://www.isixsigma.com/dictionary/dmaic/ |
