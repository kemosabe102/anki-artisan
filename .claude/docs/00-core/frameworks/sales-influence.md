# Sales & Influence Frameworks

Frameworks for sales qualification and consultative selling.

## MEDDIC

| Aspect | Description |
|--------|-------------|
| **Full Name** | Metrics, Economic Buyer, Decision Criteria, Decision Process, Identify Pain, Champion |
| **Core Elements** | 6-point qualification checklist for complex B2B sales |
| **When to Use** | For qualifying enterprise deals and ensuring no deal-killers are missed |
| **Best For** | Complex B2B sales, deal review, pipeline management |
| **Reference** | https://www.meddic.com/ |

## SPIN Selling

| Aspect | Description |
|--------|-------------|
| **Full Name** | Situation, Problem, Implication, Need-Payoff |
| **Core Elements** | Questioning sequence to uncover implied needs and build value |
| **When to Use** | During discovery calls to uncover customer pain and build urgency |
| **Best For** | Discovery calls, consultative selling, technical sales discussions |
| **Reference** | https://blog.hubspot.com/sales/spin-selling-the-ultimate-guide |
