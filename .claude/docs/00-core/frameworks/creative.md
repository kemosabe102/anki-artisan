# Creative Frameworks

Frameworks for innovation, ideation, and breakthrough thinking.

## SCAMPER

| Aspect | Description |
|--------|-------------|
| **Full Name** | Substitute, Combine, Adapt, Modify, Put to other uses, Eliminate, Reverse |
| **Core Elements** | 7 lateral thinking techniques to transform an existing idea or product |
| **When to Use** | When you need to innovate on an existing solution or break out of a creative rut |
| **Best For** | Feature ideation, product innovation, brainstorming sessions |
| **Reference** | https://www.interaction-design.org/literature/article/learn-how-to-use-the-best-ideation-methods-scamper |

## First Principles Thinking

| Aspect | Description |
|--------|-------------|
| **Full Name** | Fundamental Truths Reconstruction |
| **Core Elements** | Deconstruct to basic truths → Rebuild from scratch without assumptions |
| **When to Use** | When conventional wisdom fails or you need a radical breakthrough |
| **Best For** | Strategic innovation, redefining investment frameworks, complex engineering design |
| **Reference** | https://fs.blog/first-principles/ |
