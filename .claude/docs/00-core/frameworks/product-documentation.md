# Product & Documentation Frameworks

Frameworks for product strategy, documentation, and interviewing.

## Product Strategy Stack

| Aspect | Description |
|--------|-------------|
| **Full Name** | Mission → Vision → Strategy → Roadmap → Goals |
| **Core Elements** | Hierarchical alignment from 10-year vision down to quarterly goals |
| **When to Use** | To align daily work with long-term company direction |
| **Best For** | Defining the 'Why' and 'Where' before building |
| **Reference** | https://www.reforge.com/blog/the-product-strategy-stack |

---

## Now-Next-Later

| Aspect | Description |
|--------|-------------|
| **Full Name** | Theme-based Roadmapping |
| **Core Elements** | Time horizons based on certainty (Now=Execution, Next=Discovery, Later=Strategy) |
| **When to Use** | For communicating roadmaps without committing to fake deadlines |
| **Best For** | Product roadmapping, communicating priority to stakeholders |
| **Reference** | https://www.prodpad.com/blog/invented-now-next-later-roadmap/ |


---

## 4D Feature Framework

| Aspect | Description |
|--------|-------------|
| **Full Name** | Discover, Define, Design, Deliver |
| **Core Elements** | 4-stage pipeline to move from problem to shipped feature |
| **When to Use** | For executing on specific roadmap items (Feature Design) |
| **Best For** | Feature specification, moving from roadmap to engineering |
| **Reference** | https://www.productplan.com/glossary/feature-driven-development/ |

---

## STAR

| Aspect | Description |
|--------|-------------|
| **Full Name** | Situation, Task, Action, Result |
| **Core Elements** | Structured storytelling format for behavioral questions |
| **When to Use** | When answering behavioral interview questions or writing resume bullets |
| **Best For** | Job interviews, performance reviews, articulating achievements |
| **Reference** | https://capd.mit.edu/resources/the-star-method-for-behavioral-interviews/ |


---

## Diátaxis

| Aspect | Description |
|--------|-------------|
| **Full Name** | Diátaxis Documentation Framework |
| **Core Elements** | 4 doc types: Tutorials (learning), How-To (tasks), Reference (information), Explanation (understanding) |
| **When to Use** | When organizing technical documentation to ensure it serves the user's needs |
| **Best For** | Technical docs, knowledge bases, user manuals |
| **Reference** | https://diataxis.fr |
