# Validation Frameworks

Frameworks for rapid experimentation and hypothesis testing.

## Build-Measure-Learn

| Aspect | Description |
|--------|-------------|
| **Full Name** | Lean Startup Feedback Loop |
| **Core Elements** | Build MVP → Measure outcomes → Learn/Pivot/Persevere |
| **When to Use** | When validating new product ideas, features, or risky assumptions |
| **Best For** | Product development, hypothesis testing, moving roadmap items from 'Next' to 'Now' |
| **Reference** | https://theleanstartup.com/principles |
