# Strategy Frameworks

Frameworks for strategic decision-making, goal-setting, and risk prevention.

## Cynefin Framework

| Aspect | Description |
|--------|-------------|
| **Full Name** | Cynefin Complexity Framework |
| **Core Elements** | 5 domains: Clear, Complicated, Complex, Chaotic, Disorder |
| **When to Use** | To classify a problem environment and determine the appropriate response strategy |
| **Best For** | Strategic planning, crisis management, deciding between 'best practice' vs 'experimentation' |
| **Reference** | https://thecynefin.co/about-us/about-cynefin-framework/ |

---

## OKR

| Aspect | Description |
|--------|-------------|
| **Full Name** | Objectives and Key Results |
| **Core Elements** | Ambitious qualitative Objective + 3-5 quantitative Key Results |
| **When to Use** | For setting strategic goals and aligning teams on measurable outcomes |
| **Best For** | Quarterly planning, portfolio management, tracking agent evaluation targets |
| **Reference** | https://www.whatmatters.com/faqs/okr-meaning-definition-example |

---

## Pre-Mortem Analysis

| Aspect | Description |
|--------|-------------|
| **Full Name** | Prospective Hindsight |
| **Core Elements** | Imagine future failure → Identify causes → Implement prevention now |
| **When to Use** | Before launching high-stakes projects or deploying complex systems |
| **Best For** | Risk mitigation, SRE planning, reliable system design |
| **Reference** | https://hbr.org/2007/09/performing-a-project-premortem |
