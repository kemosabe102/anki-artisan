## Quick Reference

### 5 Whys Framework
- Primary backward-looking root cause identification
- Drill from symptom to actionable root cause (typically 5 levels)
- Evidence required at each level
- Validation: actionable AND non-circular

### SCAMPER Framework
- Secondary forward-looking improvement generation
- 7 lenses: Substitute, Combine, Adapt, Modify, Put to other use, Eliminate, Reverse
- Generate 2-5 recommendations based on root cause
- Each includes effort/impact estimates
