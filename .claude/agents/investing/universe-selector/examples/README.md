## Quick Start

```markdown
# Full validation
Task(universe-selector, "Validate ['SPY', 'QQQ', 'IWM'] for 2020-2024 backtest")

# Survivor bias only
Task(universe-selector, "Check survivor bias for ['AAPL', 'MSFT'] from 2015")

# Sector analysis
Task(universe-selector, "Analyze sector concentration for sector ETFs")
```
