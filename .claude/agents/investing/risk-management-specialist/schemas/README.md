JSON Schema definitions for input validation and output contracts.

## Contents

| Schema | Description |
|--------|-------------|
| [risk-management-specialist.schema.json](risk-management-specialist.schema.json) | Input/output contract |

## Usage

All outputs from risk-management-specialist MUST validate against the schema.

The schema extends `base-agent.schema.json` with risk-specific fields.
