## Quick Reference

The workflow agent handles 10 operation types:
- `build_workflow` - Create new workflows
- `sync_ecosystem` - Cross-document synchronization
- `optimize_workflow` - Improve workflow efficiency
- `create_command` - Build slash commands
- `maintain_registry` - Track workflow capabilities
- `analyze_bottlenecks` - Identify friction points
- `update_documentation` - Maintain workflow docs
- `create_automation` - Build hooks
- `pre_mortem` - Proactive failure analysis
- `analyze_failures` - Post-failure root cause analysis

See `delegation-examples.md` for Task() call patterns.
