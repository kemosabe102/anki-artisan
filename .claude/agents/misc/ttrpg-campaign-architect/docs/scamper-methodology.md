# SCAMPER Methodology for TTRPG Campaign Design

**Purpose**: Creative ideation framework for generating and refining campaign elements

---

## What is SCAMPER?

SCAMPER is a structured brainstorming technique using seven prompts to transform existing ideas into new possibilities. For TTRPG campaigns, it helps:

- Generate fresh plot hooks from tired tropes
- Add unexpected twists to familiar scenarios
- Deepen world elements with creative connections
- Iterate on ideas with players during sessions

---

## The Seven Techniques

### S - Substitute

**Prompt**: What can I replace while keeping the core function?

**TTRPG Applications**:
- Swap villain motivations (revenge → redemption seeking)
- Replace creature types (dragon → corrupted treant with similar threat)
- Change location type (underground dungeon → floating sky prison)
- Substitute macguffin purpose (destroy it → complete it)

**Example**:
```
Original: Evil wizard wants power
Substitute: Grieving parent wants to resurrect child (same threat, different motive)
```

### C - Combine

**Prompt**: What elements can I merge for something new?

**TTRPG Applications**:
- Merge two factions into uneasy alliance
- Combine creature traits (undead + fey = ghost court)
- Join separate plot threads at critical moment
- Blend genre elements (fantasy + heist movie structure)

**Example**:
```
Original: Thieves guild + Merchant consortium (separate factions)
Combined: Legitimate trading company secretly runs criminal network
```



### A - Adapt

**Prompt**: What can I borrow and modify from elsewhere?

**TTRPG Applications**:
- Adapt mythology (Greek gods → elemental spirits with similar roles)
- Borrow historical events (plague → magical corruption spreading)
- Use movie structures (heist film beats for dungeon infiltration)
- Adapt real cultures respectfully (inspiration, not appropriation)

**Example**:
```
Original: Generic zombie apocalypse
Adapted: Black Death structure - disease spreads via trade routes, 
        quarantines create political tension, scapegoating innocent groups
```

### M - Modify (Magnify/Minimize)

**Prompt**: What if I scaled this up or down dramatically?

**TTRPG Applications**:
- Magnify stakes (village threat → kingdom threat → world threat)
- Minimize scope (epic war → personal vendetta within the war)
- Amplify consequences (minor crime → executed publicly)
- Reduce resources (well-equipped → desperate survivors)

**Example**:
```
Original: Thieves steal valuable item
Magnified: Thieves steal item that controls weather for entire region
Minimized: Thieves steal item with sentimental value to powerful NPC
```

### P - Put to Other Uses

**Prompt**: How else could this element serve the story?

**TTRPG Applications**:
- Location repurposing (abandoned temple → bandit fortress → refugee camp)
- NPC role shifts (mentor → secret antagonist → tragic ally)
- Item function change (weapon → key → symbol of authority)
- Plot thread redirection (rescue mission → recruitment opportunity)

**Example**:
```
Original: Dungeon is just a dungeon
Put to Other Use: Dungeon is faction's secret meeting place, 
        or prison for something that shouldn't be freed
```

### E - Eliminate

**Prompt**: What can I remove to make this stronger?

**TTRPG Applications**:
- Cut redundant factions (3 criminal guilds → 1 with internal divisions)
- Simplify magic rules (remove unnecessary complexity)
- Remove "obvious" elements (no generic fantasy races)
- Eliminate safety nets (healing is scarce, resurrection impossible)

**Example**:
```
Original: Five competing merchant guilds with complex politics
Eliminated: Two guilds with clear rivalry - easier for players to track
```

### R - Reverse/Rearrange

**Prompt**: What if I flipped this or reordered it?

**TTRPG Applications**:
- Role reversal (villain was the hero, hero was the problem)
- Timeline shuffle (start at climax, flashback structure)
- Expectation inversion (dragon protects village, knights are raiders)
- Cause-effect swap (players caused the problem they're solving)

**Example**:
```
Original: Heroes stop cult from summoning demon
Reversed: Cult is trying to PREVENT summoning; heroes accidentally help it happen
```

## SCAMPER Application Workflow

### For Generating New Ideas

1. Start with a familiar trope or cliché
2. Apply 2-3 SCAMPER techniques
3. Evaluate: Is this more interesting? Playable?
4. Iterate until satisfied

### For Refining Existing Elements

1. Identify what feels weak or predictable
2. Apply technique that addresses the weakness:
   - Too familiar? → **Substitute** or **Reverse**
   - Too simple? → **Combine** or **Modify**
   - Too complex? → **Eliminate**
   - Too disconnected? → **Adapt** or **Put to Other Uses**
3. Test: Does it still fit the world coherently?

### Interactive Refinement with Users

**Process**:
1. Present original element
2. Offer 2-3 SCAMPER-transformed alternatives
3. User selects direction or requests different technique
4. Iterate until user approves

**Example Interaction**:
```
Original: "The party must retrieve a stolen crown"

SCAMPER Options:
1. [Substitute] The crown was never stolen - it was hidden by the "victim"
2. [Reverse] The party must STEAL the crown from its rightful owner
3. [Combine] The crown is one piece of a set - others are held by rivals

Which direction interests you? Or should I try different techniques?
```

---

## Quick Reference: When to Use Each Technique

| Situation | Best Technique |
|-----------|----------------|
| Idea feels too familiar | Substitute, Reverse |
| Need more complexity | Combine, Modify (magnify) |
| Too many elements to track | Eliminate, Modify (minimize) |
| Elements feel disconnected | Combine, Put to Other Uses |
| Need fresh perspective | Adapt, Reverse |
| Want to deepen existing idea | Modify, Put to Other Uses |
