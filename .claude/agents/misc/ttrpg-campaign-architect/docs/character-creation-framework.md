# Character Creation Framework

**Purpose**: Generate and integrate player characters into TTRPG campaigns

---

## Two Modes of Character Creation

### Mode A: Generate Characters

When user needs character concepts for their campaign.

**Flow**:
1. Understand the campaign context (world, story, tone)
2. Generate 4-6 diverse character concepts
3. User selects 1-3 to develop
4. Create full backstory for selected characters
5. Define party dynamics

### Mode B: Fit My Character

When user has an existing character concept.

**Flow**:
1. User describes their character
2. Develop backstory that fits the campaign
3. Connect to world elements and factions
4. Create personal arc tied to main plot
5. Suggest party dynamics with other characters

---

## Character-First Flow

When users start with a character before world/story exists.

**Principle**: The character is the seed. Everything grows from their backstory.

**Flow**:
1. **Develop Character**
   - Core concept and archetype
   - Why they are who they are (origin)
   - What they want and fear
   - Who matters to them

2. **Extract World Elements**
   - From origin → homeland, culture, society
   - From motivation → goal locations, obstacles
   - From relationships → factions, NPCs
   - From fears → threats, antagonists

3. **Generate Story Hooks**
   - Personal arc → Main plot connection
   - Character goal → Campaign climax tie-in
   - Character fear → Mid-game complication

4. **Offer Expansion**
   - Build additional party members that fit
   - Develop BBEG from backstory elements
   - Flesh out the world to support the character's journey

## Backstory Template (Bullet Points Only)

```
**📖 [Character Name]**

### Background
- Born in [location from world]
- Raised by/with [family/community context]
- Defining moment: [event that shaped them]
- Connection to [faction]: [relationship type]

### Motivation
- **Wants**: [concrete external goal]
- **Needs**: [internal growth they don't realize they need]
- **Fears**: [exploitable weakness or vulnerability]

### Relationships
- **Ally**: [NPC name] — [why they matter]
- **Rival/Enemy**: [NPC name] — [source of conflict]
- **Complicated**: [NPC name] — [it's not simple]

### Campaign Hooks
- **Early Game**: [personal stake in opening events]
- **Mid Game**: [complication that tests their arc]
- **End Game**: [how their story resolves with the main plot]
```

## Character Archetypes (Quick Reference)

Use as starting points — mix and subvert freely.

| Archetype | Core Trait | Arc Potential |
|-----------|------------|---------------|
| **Reluctant Hero** | Doesn't want responsibility | Acceptance of calling |
| **Reformed Villain** | Seeking redemption | Proving change is real |
| **Naive Idealist** | Believes in the good | Tested by harsh realities |
| **Cynical Veteran** | Seen too much | Rediscovers hope |
| **Outsider** | Doesn't belong | Finds or creates community |
| **Seeker** | Searching for something | Discovery changes everything |
| **Protector** | Guards someone/thing | Must let go to save |
| **Avenger** | Driven by past wrong | Learns cost of vengeance |
| **Heir** | Inherits power/duty | Defines own path |
| **Trickster** | Chaos and wit | Learns when to be serious |

## Integration Principles

### Connecting Characters to World
- Place origin in established location
- Tie to existing faction (member, enemy, or complicated)
- Link personal history to world history
- Use world's magic/technology in backstory

### Connecting Characters to Story
- Personal goal aligns with or opposes main conflict
- Backstory NPC appears in plot
- Character fear becomes mid-game challenge
- Arc resolution tied to campaign climax

### Connecting Characters to Each Other
- Shared history (before campaign or early sessions)
- Complementary skills (practical and dramatic)
- Conflicting beliefs (creates roleplay opportunities)
- Shared secret or goal (party cohesion)

---

## Quality Checklist

Before finalizing a character:

- [ ] Backstory uses bullet points (not prose walls)
- [ ] Motivation has clear Want, Need, and Fear
- [ ] At least one connection to world element
- [ ] At least one connection to story element
- [ ] Campaign hooks defined for early/mid/end
- [ ] Party dynamics established with at least one other character
- [ ] No mechanics or rules — just story elements
