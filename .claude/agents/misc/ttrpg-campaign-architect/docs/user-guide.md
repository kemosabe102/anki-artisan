## 🎨 Creation Modes

The agent auto-detects which mode you need based on your request.

&nbsp;

### 🌍 World Builder

*Trigger words: "world", "setting", "realm"*

Creates locations, factions, creatures, and magic systems. Perfect when you want to establish the sandbox before the story.

&nbsp;

### 📖 Story Builder

*Trigger words: "campaign", "story", "adventure"*

Creates premise, conflict, plot hooks, and campaign arcs. Use this when you have a world but need the narrative.

&nbsp;

### 👥 Character Creator

*Trigger words: "character", "PC", "backstory"*

Creates backstories, motivations, and party dynamics. Great for session zero prep or NPC development.

&nbsp;

### 🎭 Full Campaign

*Trigger words: "everything", "full campaign"*

Combines world + story into an integrated experience. The complete package.

## 🎮 Using Your Game System

The agent is **system-agnostic by default** but can incorporate rules when you share them.

&nbsp;

> 📌 **What you can share**: System name, rulebook pages, character sheet format, custom rules.

&nbsp;

> 📌 **When to share**: Early is better, but anytime works.

&nbsp;

> 📌 **What gets added**: Optional sections with stats, abilities, and challenge ratings alongside your narrative content.

&nbsp;

**Example:**
```
I'm using D&D 5e. Can you add stat blocks for the NPCs?
```

## ✨ Tips for Best Results

&nbsp;

### 1. React, Don't Restart

Tell it what to change rather than requesting something completely different.

> ❌ *"Actually, let's do something totally different"*
>
> ✅ *"I like this, but make the villain more sympathetic"*

&nbsp;

### 2. Use Inspiration Touchstones

References help dial in tone fast.

> *"Like Dark Souls but with more political intrigue"*
>
> *"Bloodborne meets The Witcher — gothic horror with morally gray monster hunters"*

&nbsp;

### 3. Ask for Alternatives

Don't settle on the first idea. The SCAMPER framework generates creative variations.

> *"Can you SCAMPER this faction?"*
>
> *"Give me three different directions for this plot hook"*

&nbsp;

### 4. Build Connections

The best campaigns have elements that reference each other.

> *"Can we tie the cult to the merchant guild we created earlier?"*
>
> *"What if this location connects to the prophecy?"*

&nbsp;

### 5. Trust the Process

Each phase builds on the last. Confirm before moving on — it's easier to adjust early than to backtrack later.
