# CEFR A1/A2 Vocabulary Deck Framework

A language-agnostic guide for creating pedagogically-sound vocabulary flashcard decks at the A1 (Beginner) and A2 (Elementary) levels, based on CEFR standards and language acquisition research.

---

## Overview

**What:** Framework for building A1/A2 vocabulary decks for any language
**Why:** Consistent, research-backed structure ensures effective vocabulary acquisition across languages
**How:** Thematic clustering with mixed word types, formal/informal register inclusion, and frequency-based prioritization

---

## CEFR Word Count Targets

The CEFR (Common European Framework of Reference for Languages) doesn't mandate specific word counts, but certification bodies and research converge on consistent estimates:

| Level | Word Count | CEFR Description | Communication Goal |
|-------|------------|------------------|-------------------|
| A1 | 500-700 | Breakthrough/Beginner | Basic phrases, personal details, survival communication |
| A2 | 1,000-1,500 | Waystage/Elementary | Routine tasks, simple exchanges, familiar topics |

**Key insight:** The first 1,000 words in any language typically cover ~80% of everyday conversation, making frequency-based prioritization essential.

## A1 Level: Survival Communication

### Target Outcomes
At A1 completion, learners should be able to:
- Introduce themselves and others
- Ask and answer simple personal questions
- Interact in simple ways if the other person speaks slowly
- Handle basic transactions (ordering food, asking directions)

### Core A1 Thematic Categories (15 domains)

1. **Personal Information**
   - Name, age, nationality, address, occupation
   - Basic identity vocabulary

2. **Greetings and Courtesies**
   - Hello, goodbye, please, thank you, excuse me
   - Formal and informal variants (if applicable to language)

3. **Family**
   - Immediate family members
   - Basic relationship terms

4. **Home and Housing**
   - Rooms, basic furniture
   - Home-related verbs (live, sleep, eat)

5. **Daily Routine**
   - Wake up, eat, work, sleep
   - Reflexive/routine verbs

6. **Food and Drink**
   - Common foods, beverages
   - Basic restaurant vocabulary

7. **Time Expressions**
   - Today, yesterday, tomorrow
   - Morning, afternoon, evening, night

8. **Days, Months, Seasons**
   - Days of the week
   - Months of the year
   - Seasons

9. **Numbers**
   - Cardinal numbers 0-100
   - Basic ordinals (first, second, third)

10. **Colors**
    - Basic color vocabulary

11. **Weather**
    - Common weather conditions
    - Temperature expressions

12. **Clothing**
    - Basic garments
    - Dressing-related verbs

13. **Body Parts**
    - Major body parts
    - Basic physical descriptions

14. **Places**
    - City, school, office, store, restaurant
    - Basic location vocabulary

15. **Transportation**
    - Common vehicles
    - Travel-related verbs

### Grammar Concepts A1 Vocabulary Must Support

A1 vocabulary should enable learners to use:
- Present tense (regular and common irregular verbs)
- Basic modal verbs (can, want, must/have to)
- Articles (definite and indefinite)
- Simple prepositions (of, to, from, in, with, on, for)
- Possessive adjectives (my, your, his/her)
- Subject pronouns
- Basic direct object pronouns
- Existential constructions ("there is/there are")
- Basic negation

### High-Frequency Function Words

Every language has a core set of function words (articles, prepositions, pronouns, conjunctions) that appear in virtually every sentence. These must be mastered early:

**Categories to include:**
- Articles (if applicable)
- Common prepositions
- Subject pronouns
- Basic conjunctions (and, but, or, because)
- Question words (who, what, where, when, why, how)
- Demonstratives (this, that)
- Basic quantifiers (all, some, many, few)

### Essential Verbs for A1

Every language has 10-15 high-frequency verbs that form the backbone of communication. Identify and prioritize:

1. **To be** (existence, identity, description)
2. **To have** (possession, auxiliary function)
3. **To do/make** (actions, causatives)
4. **To go** (movement away)
5. **To come** (movement toward)
6. **To want** (desires, requests)
7. **To be able/can** (ability, permission)
8. **To need/must** (obligation, necessity)
9. **To say/tell** (communication)
10. **To know** (knowledge, acquaintance)

Additional essential verbs: eat, drink, sleep, work, live, speak, understand, see, hear, give, take, buy, like/love

## A2 Level: Routine Communication

### Target Outcomes
At A2 completion, learners should be able to:
- Describe their background, immediate environment, and matters of immediate need
- Handle routine tasks requiring simple, direct exchange of information
- Communicate in simple, routine situations

### New A2 Thematic Categories (13 domains)

A2 builds on A1—every A2 word list assumes A1 mastery.

1. **Extended Family and Relationships**
   - Grandparents, aunts, uncles, cousins
   - Relationship status vocabulary

2. **Professions and Work**
   - Common job titles
   - Basic workplace vocabulary

3. **Travel and Tourism**
   - Airport, station, tickets
   - Booking and reservations

4. **Shopping and Transactions**
   - Stores, prices, payment
   - Shopping verbs and phrases

5. **Health and Body**
   - Symptoms, medical visits
   - Basic health vocabulary

6. **Emotions and Feelings**
   - Happy, sad, angry, worried
   - Emotional state vocabulary

7. **Hobbies and Leisure**
   - Sports, entertainment, activities
   - Free time vocabulary

8. **Nature and Environment**
   - Plants, animals, landscapes
   - Basic nature vocabulary

9. **Technology Basics**
   - Computer, phone, internet
   - Basic digital vocabulary

10. **Accommodation**
    - Apartment, rent, facilities
    - Housing search vocabulary

11. **Restaurant and Ordering**
    - Menu, ordering, paying
    - Dining vocabulary

12. **Directions and Navigation**
    - Left, right, straight
    - Giving and following directions

13. **Expressing Opinions**
    - Think, believe, prefer
    - Agreement and disagreement

### Grammar Concepts A2 Vocabulary Must Support

A2 vocabulary should enable learners to use:
- Past tenses (simple past, recent past)
- Future tense (basic)
- Conditional mood (for polite requests)
- Imperative mood (commands)
- Comparatives and superlatives
- More complex pronouns (indirect objects, combined pronouns)
- Expanded conjunctions (even if, therefore, since, while)
- Basic relative clauses

## Research-Backed Design Principles

### 1. Thematic Clustering Over Semantic Grouping

**Research finding:** Words grouped by semantic neighborhood (apple, orange, banana) actually interfere with each other and hinder retention.

**Better approach:** Thematic clustering—words related by context but not synonymous. A "restaurant" deck should include:
- Nouns (menu, bill, table)
- Verbs (order, pay, reserve)
- Phrases (I would like, the check please)
- Adjectives (delicious, expensive)

### 2. Context Sentences, Not Isolated Words

Every vocabulary item should include:
- The word/phrase
- Translation
- Example sentence in context
- Translation of the sentence
- Part of speech
- Grammatical notes (gender, etc.)
- Tags for categorization

### 3. Formal/Informal Register Inclusion

Many languages distinguish formal and informal registers. Include both from A1:

**Language-specific considerations:**
- Pronoun systems (tu/vous, du/Sie, tu/Lei, etc.)
- Verb conjugation differences
- Vocabulary choices (informal greetings vs. formal)
- When to use each register

**Recommendation:** Default to teaching formal register first for adult learners, as it's never wrong to be too polite. Include informal alternatives with clear usage notes.

### 4. Audio Inclusion

Pronunciation must be learned, not assumed. Every deck should include:
- Native speaker audio for each word
- Audio for example sentences
- Clear, slightly slower speech for beginners

### 5. Spaced Repetition Optimization

- Don't group semantically similar items consecutively
- Mix word types within study sessions
- Review function words more frequently than content words initially

## Language-Specific Adaptations Required

When adapting this framework to a specific language, address:

### Grammatical Features
- **Grammatical gender:** Include gender markers (m/f/n) for nouns
- **Noun classes:** Document relevant classifications
- **Article systems:** Note definite/indefinite article usage
- **Case systems:** Include case markers where relevant
- **Verb conjugation patterns:** Note irregular verbs
- **Aspect distinctions:** Address perfective/imperfective if applicable

### Writing System
- **Script:** Note if non-Latin script requires additional learning
- **Romanization:** Include transliteration if helpful
- **Tone marks:** Include for tonal languages
- **Character components:** Note radicals/roots for logographic systems

### Cultural/Pragmatic Features
- **Formality systems:** Document T-V distinction or honorific systems
- **Politeness markers:** Note required politeness vocabulary
- **Cultural vocabulary:** Include culturally significant terms
- **Loanwords:** Note where English/international words are used

### Phonological Considerations
- **Difficult sounds:** Highlight sounds not in learner's L1
- **Stress patterns:** Note stress rules
- **Tone patterns:** Document tones for tonal languages
- **Liaison/sandhi:** Note connected speech patterns

## CSV Schema for Deck Files

```
word,translation,phrase,phrase_translation,part_of_speech,gender,tags
```

### Field Definitions

| Field | Description | Example |
|-------|-------------|---------|
| word | Target language word/phrase | buongiorno |
| translation | English translation | good morning |
| phrase | Example sentence (≤6 words recommended) | Buongiorno! Come sta? |
| phrase_translation | English translation of phrase | Good morning! How are you? |
| part_of_speech | Grammatical category | noun, verb, adjective, etc. |
| gender | Grammatical gender (if applicable) | m, f, n, n/a |
| tags | Category tags for filtering | greetings, formal |

### Phrase Guidelines
- Keep phrases to 5-6 words maximum (for TTS cost control)
- Use natural, commonly-heard phrases
- Include the target word in context
- Prefer complete, usable sentences

## Quality Checklist

Before finalizing decks, verify:

- [ ] Word count targets met (~50 words per deck)
- [ ] Thematic clustering applied (mixed word types per deck)
- [ ] Both formal and informal registers included (where applicable)
- [ ] Example sentences provided for all entries
- [ ] Part of speech marked for all entries
- [ ] Grammatical gender/class noted (where applicable)
- [ ] High-frequency verbs prioritized
- [ ] Function words included early
- [ ] Tags applied for filtering
- [ ] Audio pronunciation planned

## Summary

Effective A1/A2 vocabulary decks should:

1. **Target 350 words at A1** organized into 7 thematic decks
2. **Target 350 additional words at A2** organized into 7 thematic decks
3. **Use thematic clustering** with mixed word types (nouns + verbs + adjectives together)
4. **Include both registers** (formal/informal) from the start
5. **Provide context sentences** for every vocabulary item
6. **Prioritize high-frequency words** including function words and essential verbs
7. **Note grammatical features** (gender, class, irregularity)
8. **Include audio** for pronunciation learning

This framework provides the structure; language-specific research fills in the vocabulary.
